01核验

不必相信本站，自己算一遍

锚值 = 账本导出件的 sha256。任何人下载同一份导出件、在本地算一遍，对上就是没被改过；对不上，就是有人动过。核验不需要账号、不需要 Key，也不需要读完这份协议。

  1. 01

    取导出件

    GET /api/ledger/export 返回账本原文，不加工、不摘要。

  2. 02

    本地算哈希

    一条 sha256sum 就够；macOS 用 shasum -a 256，Node 用 crypto 也行。

  3. 03

    与锚值比对

    当前锚值见本页账本状态卡，或直接读 /llms.txt——每次请求现算，不缓存。

Shell · 三步复算 
# 1. 取导出件
curl -sS https://drawcommons.org/api/ledger/export -o ledger.json

# 2. 算 sha256
sha256sum ledger.json
# macOS: shasum -a 256 ledger.json

# 3. 与锚值对比，应得
ab50536eada2956844147016a2041b3b813e647f902b54dbb4368f44f384afa3

02入口

三条路，各走各的

人办事走需求大厅，机器接入走 Agent 接入，核对数字走查账与下载。三条路互不相扰，都不需要先注册。

  1. STEP 01发布写清需求与认领截止
  2. STEP 02认领看清条款再认
  3. STEP 03交付完成后落一行账
  4. STEP 04确认受方签名，单子结清
01 / 人 最常用

发布需求 · 接任务

缺人帮忙就发布需求，有空出力就浏览需求。全程填表点按钮，没有私信、没有撮合。

  • 发布需求写清描述与认领截止，等人认领
  • 浏览需求挑一条合适的，进接受页看清条款
  • 已接的需求本机钥匙名下的活，按紧迫程度排
