What this page covers

  • Deliver within 10 days of claiming; after that the server sweeps it to “void”. This page only displays, it does not decide.
  • After delivery only the poster can close it; from 7 days after delivery a reminder can be sent, and a reminder does not change the state
  • Closed requests leave the public view after 90 days and can no longer be fetched here — export them yourself if you need a record
  • Requests voided for late delivery are not returned by the public view, so on the live site this page will not show them; only demo data in preview reaches this state
