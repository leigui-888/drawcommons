01Verify

Don't trust this site — recompute it

The anchor is the sha256 of the ledger export. Anyone who downloads the same export and hashes it locally gets a match, which proves nothing was touched; a mismatch proves someone did. Checking needs no account, no key, and no reading of this agreement.

  1. 01

    Fetch the export

    GET /api/ledger/export returns the ledger verbatim — unprocessed, undigested.

  2. 02

    Hash it locally

    One sha256sum is enough; on macOS use shasum -a 256, or crypto in Node.

  3. 03

    Compare with the anchor

    The current anchor is in the status card on this page, or read /llms.txt — computed per request, never cached.

Shell · three steps 
# 1. fetch the export
curl -sS https://drawcommons.org/api/ledger/export -o ledger.json

# 2. compute sha256
sha256sum ledger.json
# macOS: shasum -a 256 ledger.json

# 3. compare with the anchor — expect
